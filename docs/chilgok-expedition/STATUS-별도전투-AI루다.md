# 칠곡 원정대 진행 현황 · 남은 작업 (2026-10-18)

갓루다님 요청 사항의 **한 것 / 검증 범위 / 못 한 것 / 앞으로 할 것**을 한 곳에 정리했어요.
(코드: `src/battle/block_B.js` 본선, `src/squad/block_Q.js` 별도전투, 빌드: `game/index.html`)

## 1. 지금까지 한 것
### 공격 대상 점수 함수 (별도전투 + 본선 공통)
- `점수 = 100/hp + 공격력(위협도) × 0.1` → AI는 점수가 가장 높은 대상을 공격 (`scoreTarget`, 본선 `TBScore`, 별도전투 `SQ.scoreTarget`).
- 별도전투는 실행 테스트 통과. 본선은 문법 검사·빌드까지만 했고, 만 명 규모 실행 테스트는 느려서 못 했어요.
- 본선은 만 명 중 무작위 표본(`bestOf`)에서 최고점을 고르는 방식이라 항상 정확한 최고점은 아니에요.

### 안내문 "5000" → 만 명
- 현재 소스는 `NSIDE`(10000) 값을 그대로 써서 "국군 10000 : 북한군 10000"으로 나와요. 소스에 "5000" 없음. 스크린샷은 예전 캐시 빌드.

### 별도전투 → 본선전투 하나로 연결
- 전투 시작(Enter) → **별도전투(10 대 10) 먼저** → 끝나면 자동으로 **본선전투(1만 대 1만)**.
- 이긴 쪽 1만 명 공격력 **+5** (국군 승리: 국군 +5, 북한군 승리: 북한군 +5). 본선 시작 때 전투마다 0으로 초기화 후 적용 (`SQM.bonus`, `SQM.nk`).
- **Esc** = 별도전투 건너뛰기(확인창) → 보상 없이 바로 본선. 타깃 선택 중 Esc는 선택 취소.
- 테스트: Enter → 별도전투 시작(chain) → Esc → 본선(intro) 진입, 오류 없음.

### 별도전투 맵·화면
- 맵: 강(흐르는 물결, 헤엄 칸 이동력 2점), 다리 2개, **초록 계단식 산**(5×5 + 3×3, 한 칸씩만 오르내림, 오를 때 이동력 +1), 숲(통과 불가·엄폐), 바위산, 돌담, 진흙·논, 꽃, 먼 산·소나무, 잔디 바닥.
- **가시 함정**: 밟으면 **-5** (다시 밟아도 계속 발동). 공병 함정(-20)은 그대로.
- **수영**: 강 칸의 병사는 물에 반쯤 잠겨 좌우 반전·기울기·물결 파문·"🏊 수영!" 표시.
- 병사 다양화: 신규 병종 **정찰병**(이동 5, 기습 사격 160%)·**척탄병**(수류탄 범위 피해) + 얼굴 변형(피부·머리색·안경·콧수염·상처·머리띠).
- 클릭 개선: 캐릭터 투명 영역이 타일 클릭을 막지 않고, 큰 머리 뒤의 이동·공격 가능 칸도 누를 수 있어요.
- **맵 확장**: 오른쪽 위 "⛶ 맵 확장" 버튼 + F 키 (기존 확장 버튼은 하단 패널에 가려져 있었음). 확장 시 카메라가 더 가까워져요.
- 제목 배너, 비네팅, 패널 그림자 등 디자인 손질.

## 4. AI루다 설계 (확정 + 추천)
**확정(구현됨)**: "4번 부대 앞으로 10칸", "1~10번 왼쪽 5칸", "3번 5번 중앙으로", "전체 진군", "7번 정지", "자유행동", "보고", "취소", "도움말". 명령은 우리 턴에 저장되고 **Space(턴 종료)** 때 병사별로 최대 5칸씩 이동. 명령 안 받은 부대는 기존 자동 행동.

**AI루다에게 넣으면 좋은 것 (추천)**
1. 명령 확인·되돌리기("4번 부대 앞으로 → 취소")
2. 턴 시작 보고: 전황, 약해진 부대, 위협 방향
3. 부대 별명/묶음: "왼쪽 날개=1~10번", "예비대=91~100번"
4. 조건 명령: "체력 50% 이하면 후퇴"
5. "알아서 해줘" 자동 전술(점수 함수 기반)
6. 턴당 명령 횟수 제한(명령 포인트) — 긴장감
7. 성격 반응(~냥), 승패에 따른 대사
8. (선택) Upstage LLM으로 자연어 해석, 키 없으면 지금의 오프라인 해석으로 자동 대체

## 5. 방진 후보 10개 (갓루다님 선택 필요)
부대 100개를 슬롯에 배치해 한 번에 이동·전개하는 방식으로 구현 예정.
1. **학익진** — 중앙 후퇴·양 날개 전진(포위)
2. **어린진** — 물고기 비늘, 전방 두껍게 돌파
3. **장사진** — 한 줄 길게, 좁은 길·다리 통과
4. **방원진** — 원형 방어, 중앙에 지휘·의무
5. **봉시진** — 화살촉형, 중앙 돌파
6. **언월진** — 반달형, 중앙이 앞으로
7. **곡진** — 오목한 U자, 적을 가운데로 유인
8. **쐐기진(추행진)** — 뾰족한 쐐기, 한 점 집중 돌파
9. **횡렬(일자진)** — 넓게 한 줄, 화력 최대
10. **분산 유격진** — 소집단 흩어져 측면 기습

## 6. 만 대 만 전투를 재미있게 (함께 정할 안)
- **이름 있는 병사**: 1만 명 중 일부(예: 부대마다 1명)에게 이름·성격·한 줄 사연 → 죽으면 알림("3번 부대 박상병 전사").
- **영웅 승급**: 많이 처치한 병사는 베테랑(공격력 +, 외형 표시), 부대 단위 사기 수치.
- **부대 개성**: 부대별 특성(사격 부대/돌격 부대/의무 부대) → AI루다 명령과 연결.
- **지형·이벤트**: 강·다리·고지·함정이 본선에도 영향, 날씨·야간.
- **작전 목표**: 고지 점령, 다리 방어 등 단계형 목표 + 보상.
- **AI루다 연출**: 명령 결과 보고, 칭찬/걱정 대사, 승리 시 축하.
- **별도전투 보상 확장**: 이긴 쪽 +5 외에 특수 부대 지원 등.
