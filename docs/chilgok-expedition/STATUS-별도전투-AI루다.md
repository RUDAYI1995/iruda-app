## 1. 지금까지 한 것
### 공격 대상 점수 함수 (별도전투 + 본선 공통)
- `점수 = 100/hp + 공격력(위협도) × 0.1` → AI는 점수가 가장 높은 대상을 공격 (`scoreTarget`, 본선 `TBScore`, 별도전투 `SQ.scoreTarget`).
- 별도전투는 실행 테스트 통과. 본선은 문법 검사·빌드까지만 했고, 만 명 규모 실행 테스트는 느려서 못 했어요.
- 본선은 만 명 중 무작위 표본(`bestOf`)에서 최고점을 고르는 방식이라 항상 정확한 최고점은 아니에요.

### 안내문 "5000" → 만 명
- 현재 소스는 `NSIDE`(10000) 값을 그대로 써서 "국군 10000 : 북한군 10000"으로 나와요. 소스에 "5000" 없음. 스크린샷은 예전 캐시 빌드.

### 별도전투 → 본선전투 하나로 연결
- 전투 시작(Enter) → **별도전투(10 대 10) 먼저** → 끝나면 자동으로 **본선전투(1만 대 1만)**.
- 이긴 쪽 1만 명 공격력 **+5** (국군 승리: 국군 +5, 북한군 승리: 북한군 +5). 본선 시작 때 전투마다 0으로 초기화 후 적용 (`SQM.bonus`, `SQM.nk`).
- **Esc** = 별도전투 건너뛰기(확인창) → 보상 없이 바로 본선. 타깃 선택 중 Esc는 선택 취소.
- 테스트: Enter → 별도전투 시작(chain) → Esc → 본선(intro) 진입, 오류 없음.

### 별도전투 맵·화면
- 맵: 강(흐르는 물결, 헤엄 칸 이동력 2점), 다리 2개, **초록 계단식 산**(5×5 + 3×3, 한 칸씩만 오르내림, 오를 때 이동력 +1), 숲(통과 불가·엄폐), 바위산, 돌담, 진흙·논, 꽃, 먼 산·소나무, 잔디 바닥.
- **가시 함정**: 밟으면 **-5** (다시 밟아도 계속 발동). 공병 함정(-20)은 그대로.
- **수영**: 강 칸의 병사는 물에 반쯤 잠겨 좌우 반전·기울기·물결 파문·"🏊 수영!" 표시.
- 병사 다양화: 신규 병종 **정찰병**(이동 5, 기습 사격 160%)·**척탄병**(수류탄 범위 피해) + 얼굴 변형(피부·머리색·안경·콧수염·상처·머리띠).
- 클릭 개선: 캐릭터 투명 영역이 타일 클릭을 막지 않고, 큰 머리 뒤의 이동·공격 가능 칸도 누를 수 있어요.
- **맵 확장**: 오른쪽 위 "⛶ 맵 확장" 버튼 + F 키 (기존 확장 버튼은 하단 패널에 가려져 있었음). 확장 시 카메라가 더 가까워져요.
- 제목 배너, 비네팅, 패널 그림자 등 디자인 손질.

### AI루다 참모 (실행 검증 완료)
- 본선전투 중 왼쪽 아래 채팅 패널, 따라다니는 고양이(원형 이미지), 한국어 명령 해석, 100개 부대(1~98번 100명, 99·100번 100명).
- 검증: "4번 부대 앞으로 10칸 5번 부대 왼쪽 6칸" → 두 부대 100명씩 이동 명령 → Space(턴 종료) 후 4번 앞으로, 5번 왼쪽으로 이동. "보고" 명령 동작. 입력창 타이핑 중 게임 키 무시.
- 이동 방식: 명령받은 병사가 한 칸씩 번갈아 5라운드, 막히면 같은 편 병사와 자리를 바꿔 지나감. 2턴 연속 못 움직이면 제자리 방어로 전환.
- 알려진 한계: 자리 바꾸기 때문에 부대 대형이 조금 흐트러져요(부대 중심이 몇 칸 밀림). 방진 구현 때 슬롯 배치로 보완 예정.

### 방진 4개 (구현·검증 완료)
- 채팅에 "학익진 / 장사진 / 방원진 / 쐐기진" 또는 패널 버튼, "진형 해제"로 풀기. 100개 부대가 진형 자리로 이동(부대 안 10×10 모양 유지, 턴당 8칸).
- 학익진: 중앙 후퇴·양 날개 전진, 5턴 / 장사진: 폭 7×길이 14 종대, 9턴 / 방원진: 원형, 12턴 / 쐐기진: 앞은 삼각·뒤는 13폭 화살촉, 13턴.
- 검증: 4개 모두 1만 명 전원에게 목적지가 걸리고 대부분 겹침 없음(방원진만 40명 겹침), 진형 해제 정상. 실제 전개가 끝까지 도달하는 장기 시뮬레이션은 못 했어요.
- 예비 부대(99·100번)는 예비 자리에 따로 배치, 필드 밖으로 나가면 진형 전체를 필드 안으로 밀어 넣어요.

### 개성 요소 (구현·검증 완료, 2026-10-18)
- **부대 특성**: 판마다 100개 부대가 사격(공격 +15%)·돌격(총검 +30%·행군 빠름)·방패(받는 피해 -20%)·의무(턴마다 +6 회복) 중 하나(각 25부대). 적도 같은 규칙. 채팅 "사격 부대 앞으로 10칸", "특성"으로 목록 확인.
- **이름 있는 정예**: 아군 100명·적 100명(부대마다 1명). 체력 ×1.5, 공격 ×1.2. 아군 정예 전사 시 AI루다가 이름·계급·사연으로 알려요. 적 정예는 격파 시 표시.
- **베테랑 승급**: 3킬 달성 시 공격 +20% (정예가 승급하면 AI루다가 알림, 나머지는 턴 보고에 인원수).
- **임무**: 판마다 5개 중 무작위 1개(철벽 방어·정예를 지켜라·루샤 사냥·전차 격파·선제 공세). 성공 시 국군 공격력 +3. 화면 왼쪽 위에 표시, 채팅 "임무"로 확인.
- **AI루다 연출**: 임무 안내, 매 턴 전황 한 줄 + 격려/걱정, 승패 대사, 정예 전사·베테랑 승급 알림.
- 검증: 정예 100/100, 특성 2500씩, 임무 무작위 배정·HUD 표시, 특성 부대 명령 2500명 적용, 오류 없음. 아직 못 한 것: 베테랑 승급·임무 성공/실패 판정이 실제 전투 끝까지 가서 작동하는지(장기 시뮬레이션), 정예 병사를 화면에서 눈으로 구분하는 표시(현재는 AI루다 알림만).

## 4. AI루다 설계 (확정 + 추천)
**확정(구현됨)**: "4번 부대 앞으로 10칸", "1~10번 왼쪽 5칸", "3번 5번 중앙으로", "전체 진군", "7번 정지", "자유행동", "보고", "취소", "도움말". 명령은 우리 턴에 저장되고 **Space(턴 종료)** 때 병사별로 최대 5칸씩 이동. 명령 안 받은 부대는 기존 자동 행동.

**AI루다에게 넣으면 좋은 것 (추천)**
1. 명령 확인·되돌리기("4번 부대 앞으로 → 취소")
2. 턴 시작 보고: 전황, 약해진 부대, 위협 방향
3. 부대 별명/묶음: "왼쪽 날개=1~10번", "예비대=91~100번"
4. 조건 명령: "체력 50% 이하면 후퇴"
5. "알아서 해줘" 자동 전술(점수 함수 기반)
6. 턴당 명령 횟수 제한(명령 포인트) — 긴장감
7. 성격 반응(~냥), 승패에 따른 대사
8. (선택) Upstage LLM으로 자연어 해석, 키 없으면 지금의 오프라인 해석으로 자동 대체

## 6. 만 대 만 전투를 재미있게 (함께 정할 안)
