칠곡 원정대 (대구 칠곡 관광 3D 어드벤처)

실행: index.html 을 브라우저(크롬 등)로 열면 돼요. three.min.js 를 같은 폴더에서 먼저 불러오고(인터넷 없이도 실행됨), 없을 때만 온라인에서 받아와요.

파일
- index.html     게임 본체 (코드 전체)
- sprites.js, sprites_dir.js   마스코트 캐릭터 이미지
- textures.js    바닥/강/다리 등 사진 텍스처
- trees.js       나무 이미지
- shops.js       왜관 시내 상가 이미지
- units.js       국군/북한군 병사(앞/뒷모습), 전차(앞/뒤/옆) 이미지
- mountains.js   먼 산(팔공산, 유학산, 치키봉, 가산) 이미지
- three.min.js   3D 라이브러리(three.js r128) — 인터넷 없이도 실행되게 같이 넣어뒀어요

조작: 방향키/WASD 이동, Space 점프, E 상호작용/공격, M 지도, F 맵 확장(전체 화면)

하늘섬 (새로 추가된 구역)
- 기존 맵의 가장 왼쪽 끝(동쪽 가장자리, z≈1100) 너머 허허벌판에 이어 붙인 구름 위 섬이에요. 기존 맵은 그대로예요.
- 가는 법: 왜관~기념관 길에서 화면 왼쪽 끝(월드 x=620)까지 걸어가면 벽돌 오르막이 시작돼요. 또는 M 지도의 맨 끝 '하늘섬'을 눌러 바로 갈 수 있어요.
- 오르막 → 시작 광장 → 하늘길 → 빛나는 아치 문(관문 섬) → 하늘길 → 오벨리스크 섬 순서로 걸을 수 있어요.
