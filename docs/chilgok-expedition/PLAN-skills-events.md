# 턴제 상태 효과(집중·독) · 가스병 — 구현 기록 (V85)

코드: `src/battle/block_B.js` (이벤트·효과·가스병), `src/battle/block_F.js` (아이콘·가스 연기). 디버그: `window.TBEvents`, `window.TBEffects`.

## 1. 이벤트 (정의 + 전부 발생)
| 이벤트 | 데이터 | 언제 |
|---|---|---|
| `OnBattleStart` | `{}` | 전투 시작 (적 전체에 집중이 붙는 시점) |
| `OnTurnStart` | `{turn, side}` | 그 편의 행동이 시작될 때: `rok` = 국군 일제 사격(내가 턴을 끝낸 직후), `nk` = 적 행동 시작 |
| `OnTurnEnd` | `{turn, side}` | 그 편의 행동이 끝났을 때 |
| `OnDamaged` | `{target, source, amount, kind, hpAfter, lethal, focusBonus}` | 피해를 입었을 때. `source` = 공격한 유닛(독은 null), `kind` = `attack`/`dot` |
| `OnKilled` | `{target, source}` | HP 가 0 이 된 직후 |

## 2. 등록/해제
`TBEvents.on(type, fn)` 은 해제 함수를 돌려줘요. 효과는 **종류별로 리스너를 한 번만** 등록해요: 그 효과가 처음 붙을 때 등록, 마지막 효과가 떨어지면 해제(1만 명에게 걸어도 리스너는 1개). `TBEffects.listening("focus")` 로 확인할 수 있어요.

## 3. 독 (DotEffect)
- `OnTurnStart` 에 반응해, 그 편 유닛에게 매 턴 피해(기본 10). 되돌리기가 되도록 상태 복원 묶음 안에서 처리해요.
- 지금 독을 붙이는 건 **가스병뿐**이에요(현재 공격은 총·대포뿐). 대신 모든 공격(`AttackCommand`)이 `fxs` 목록으로 효과를 실어 보낼 수 있어서, 독침 같은 공격이 생기면 목록만 달면 돼요.
- 다시 걸리면 지속 턴을 늘리지 않고 **갱신**(더 긴 쪽).

## 4. 집중 (FocusEffect)
- 게임 시작 때 **적 전체**(병사 1만 + 언덕 사수·전차·전투기·루샤)에 부여. 걸려 있는 동안 **첫 피격 피해 +50%**, 맞으면 해제(빗나가면 유지). 독 피해에는 반응하지 않아요.
- 확인한 값: 전투 시작 직후 집중 10017 개, 1턴 일제 사격 뒤 9972 개로 줄어요(맞은 만큼 해제).

## 5. 화면 표시
- 유닛 머리 위 아이콘: 🎯(집중) · ☠(독) (카메라 가까운(반경 60) 유닛만 최대 300개 — 1만 개 전부 그리면 느려서).
- 독 걸린 유닛은 체력바가 노란 연두색, 피해 숫자는 `☠ -10` 초록, 집중 보너스는 `🎯 -60`.
- 왼쪽 위 정보창에 `🎯 집중 N명 · ☠ 독 M명 · 🧪 가스병` 한 줄.

## 6. 가스병
- 국군 쪽 3개(`gx -26/0/26`). **5턴마다**(턴 5, 10, …) 국군 일제 사격 때 각 병이 적 한 덩어리(가까운 10명)에 독가스를 쏴요 → 병 3개 = 최대 30명. 독 3턴, 매 턴 -10.
- 연기 + 포물선 발사 효과, 전투 로그에 "가스병 3개가 독가스를 살포! 적 N명 중독".

## 7. 되돌리기 연동
스냅샷에 효과 상태(집중 유무, 독 남은 턴)를 넣었어요. 우클릭 되돌리기로 효과가 붙기/떨어지기/독 피해가 모두 되돌아가요. 공격 한 건만 되돌릴 때도 집중과 독이 원래대로 돌아와요.

## 8. 어그로 (토끼·루샤에게 총알이 몰리지 않게)
- 토끼: 한 턴에 적 전체가 쏘는 총알 **최대 2발**(기존 유지). 루샤: 국군 쪽이 쏘는 총알 **최대 3발**(이번에 추가). 나머지 모든 사격은 서로 마주한 상대 유닛에게만 가요.

## 한계
- 독 피해는 유닛이 가까이 있을 때만 숫자가 떠요(멀면 조용히 깎여요).
- 가스병은 국군 쪽만 있어요(북한군은 없음). 병 모양/연기는 임시 그림이에요.
- 효과 종류가 2개뿐이라 툴팁 설명창은 아직 없어요(아이콘 + 정보창 한 줄).
