공통 설정은 `MESHY-PROMPT-토끼.md` 와 같아요 (Image to 3D, A-pose, Symmetry On, 12,000~25,000 폴리, 알베도 색칠만, .glb, 동작 `idle/walk/run/jump/hit/cheer` + 아래 전용 동작).
**주의:** 아래 생김새는 동물 종류와 게임 속 역할로 쓴 초안이에요. 실제 그림의 색·소품과 다르면 해당 문단만 원본 그림에 맞게 고쳐 주세요 (원본 그림을 같이 업로드하는 게 가장 정확해요).

공통 앞부분(모두 동일):
```
A cute chibi animal hero mascot, 2.5-head-tall proportions, big round head, short chubby body, rounded paws and feet, glossy black eyes with white highlights, simple clean cartoon style, smooth stylized 3D character like a mobile game mascot. Neutral standing A-pose, facing forward, full body, symmetrical, game-ready low poly, clean topology, no background.
```
공통 Negative:
```
realistic fur, photorealistic, extra limbs, text, watermark, logo, background, scenery, complex accessories, thin floating parts, holes, noisy texture, uneven proportions
```
