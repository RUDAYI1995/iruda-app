# V82 — 대구 가는 길 · 낙하산 (구현 기록)

코드: `src/daegu/block_D.js` (패치 `src/patch_w.py` 에서 `PATH_MIN_Z` 등 몇 줄만 바꿔요). 전부 임시 모델/코드 생성이고, 고화질 그림이 오면 갈아 끼울 자리예요.

## 한 것
- **맵 늘리기**: 남쪽으로 z -40 → -3420 (약 3380 유닛, 걸어서 ~36초). 왜관 시내 바로 아래 막힌 곳이 대구 가는 길이에요.
  - 가로 10배는 **못 했어요**: 서쪽(x<-620)은 농촌 마을, 동쪽(x>620)은 하늘섬이 이미 차지하고 있어서 가로를 넓히면 둘 다 옮겨야 해요. 대신 세로를 크게 늘렸어요. (가로 확장은 마을/하늘섬 위치를 옮기는 별도 작업)
- **길**: 스플라인 3D 띠(차선·중앙분리대·방호벽·가로등·초록 문형 표지판). 구간
  1. 국도 4호선 평지 (z -40~-1000) — 차만 다녀요(사람이 앞에 서면 차가 멈춰요)
  2. 고가 언덕길 (z -1000~-1470) — 기둥 위, 최대 높이 23
  3. 대구 관문 고개 (z -1440~-1790) — 높이 최대 ~330 의 뾰족한 3D 산(안개 영향 없음)을 가르고 지나가는 길. 산은 걸어서 못 올라가요
  4. 대구 북구 칠곡 아파트 단지 (z -2150~-2700) — 20~30층 아파트 ~30동(동 번호판)
  5. 대구 도심 (z -2700~-3420) — 가로 길 3개, 건물 줄, 가게 간판, 임시 대구역/83타워/동대구역(광장 포함)
- **차**: InstancedMesh 130대(버스/트럭 일부), 차선별 속도, 밤에 헤드라이트·빛줄기. **탈 수 있는 차 3대**(승용차·택시·버스, E로 타고 내림, 고가도로 위에선 못 내림).
- **가게 안**: 도심 가게 5곳 들어갈 수 있어요(편의점, 카페, 호떡집, 약방, 막창집…). 점원과 E 대화, 문 쪽 E 로 나가기. (지금은 방 모양만)
- **낙하산**: 하늘섬(높이 40~900)에서 B → 일정한 속도(22/초)로 내려오고 방향키로 날아가요. 땅에 닿으면 접혀요.
- **산 이름**: 뒷배경 큰 산 이름을 칠곡 산 이름으로 바꾸는 중 — 코드/말풍선에서 팔공산 표기를 뺐고(가산 정상 말풍선 → 유학산), 확인된 이름은 유학산(839m)·가산(901.6m)뿐. 나머지는 **임시 이름**이라 실제 지명 확인 후 확정해야 해요.

## 한계 (정직하게)
- 이 환경은 CPU 렌더링이라 실제 GPU 프레임 수/밤 분위기/소리는 못 봤어요. 밤 불빛은 코드만 확인.
- 도로 모양은 지도 앱 없이 대략(칠곡에서 대구로 내려오는 방향)으로 잡았어요. 실제 지도와 같지 않아요.
- 5번째와 6번째 가게: 6곳 중 5곳만 길가에 자리가 나왔어요(광장 때문에 한 곳 빠짐).
- 가게 방, 건물, 83타워 등은 상자/원통 임시 모델이에요.
- 차끼리 부딪히지 않게 하는 처리는 차선별 일정 속도뿐이라, 한 차가 멈추면 뒤차가 겹칠 수 있어요.
- 미니맵/세계 지도는 아직 대구 구역을 그리지 않아요.
