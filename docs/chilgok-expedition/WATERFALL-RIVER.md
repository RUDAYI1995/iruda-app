# 폭포 + 강 (V57)

참고: `source-images/` 의 폭포 사진(로우폴리 협곡 폭포)을 기준으로 호국의 다리 강 상류를 바꿨어요.

## 무엇이 바뀌었나
- 강은 이제 **서쪽 협곡 폭포(x≈-300)에서 시작**해 동쪽으로 흘러 **호국의 다리 밑(x=0)** 을 지나 **동쪽 바위산 동굴(x≈548)** 로 들어가요.
  (다리는 그대로이고 강과 직각으로 가로질러요. 강폭: 개울 ~80 → 다리 밑 240.)
- 물: 사진 물 텍스처 대신 **셰이더 물**(흐르는 잔물결, 깊이 색, 하늘 반사, 햇빛 반짝임, 가장자리·교각 물거품, 폭포 아래 물보라). 낮/밤 밝기와 안개 색을 따라가요.
- 폭포: 절벽 면을 따라 흐르는 물줄기 셰이더 + 물안개 스프라이트 30개 + 폭포 위 물길.
- 지형: 절벽(로우폴리 높이지도, 회색 바위 + 라임 풀 윗면), 소나무 ~120그루, 바위, 갈대, 버섯. 모두 합쳐서 그려요.
- 땅에 강 모양 **구멍**을 냈고(`cutGround`), 강바닥/둑을 따로 만들었어요.
- 강 구간(z 548~832)의 옛 가로수는 안 심어요 (물 위에 서 있던 나무). 다리 배는 물높이에 맞춰 내렸어요.
- `plain`(멀리 보이는 안개 바닥)을 y=-0.6 → -3 으로 내렸어요 (물과 겹쳐 깜빡이는 현상 방지; 16비트 깊이 버퍼 기기 대비).
- 이동: 강물(다리 길 제외)·절벽·동쪽 바위산은 `ROCK_RECTS`로 막고, 절벽은 `CAM_RECTS`로 카메라도 막아요.

## 파일
- `src/waterfall/block_W.js` : 폭포/강 전체 (월드가 만들어진 뒤 첫 프레임에 `window.riverTick` 이 한 번 붙여요)
- `src/waterfall/patch_w.py` : 게시본 index.html 에 block_W + 4개 소패치(가로수 건너뛰기 2, 배 높이, tick 훅, plain 높이 2)를 적용
- `shot.js / walk.js / reg.js / night.js` : 스크린샷·이동·12지점 비교·밤 확인 테스트
- `game/index.html` : V57 완성본 (다른 파일은 게시된 아티팩트에서 받으세요)

## 검수 결과 (V57)
- 오류 없음, 폭포·강·다리·동굴 스크린샷 확인 (낮/밤).
- 이동 시뮬레이션: 다리 건너기 OK, 강 가장자리/절벽/동쪽 바위산에서 막힘 OK.
- 12지점 비교(이전 게시본 vs 새 본): 12곳 중 2곳만 완전 동일. 강 주변(0,150~900), 멀리 강이 보이는 곳(500,300 등)은 당연히 바뀜.
  (0,1650)은 땅 구멍 교체로 길 깜빡임(소프트웨어 렌더링 z-fight)이 사라진 차이.
- 한계: 실제 GPU 프레임·움직이는 물의 실제 느낌은 갓루다님 PC에서 확인 필요. 물 셰이더가 화면 전체 픽셀 연산이라 저사양에서 무거우면 알려주세요.

# 스카이캣 항공 (V58) — 3분마다 하늘을 나는 거대한 고양이 비행기
- 참고: `source-images/skycat_plane_reference.webp` (파란 고양이 A380, "SKY CAT AIRLINES", 꼬리 "CAT AIR")
- `src/waterfall/block_P.js` : 비행기 전체(절차적 3D). `patch_w.py` 가 block_W 뒤에 같이 붙여요.
- 모델: 고양이 머리 동체(눈·귀·코·미소·수염·이마 줄무늬), 이층 창문, 문, 발자국, 글자(그림으로 그려서 동체에 입힘), 후퇴익 + 윙렛, 엔진 4기(발자국 로고, 흡입구 링), 꼬리날개 로고, 항법등(빨강/초록) + 점멸 스트로브.
- 비행: 월드가 만들어지고 15초 뒤 첫 비행, 이후 **180초마다**. 한 번에 80초, 플레이어 앞쪽 600 거리의 차선(p.z+600)을 따라 x 방향으로 가로질러요 (옆모습이 보임). 높이 ≈ 68.
- 주의: 산 배경 카드(940~1700 거리, 깊이쓰기 없음)에 가려지지 않으려면 비행기가 ~900보다 가까워야 해요 → 차선 600.
- 한계: 사진 그대로의 질감은 아니에요(그림+3D 조합). 카메라가 아래를 보는 시점이라 하늘이 화면 위쪽 10%뿐이라, 비행기가 화면 위쪽에 걸쳐 보여요.

# 마우스 시점 + C 고정 (V59)
- 게임 화면 위에서 마우스를 **위로** 올리면 하늘 쪽을 보고, **아래로** 내리면 내려다봐요. 가운데(±14%)는 원래 시점. 부드럽게 따라와요.
- **C** : 시점 고정 / 풀기 토글 (토스트로 알려줘요). 고정하면 마우스를 움직여도 안 바뀌어요.
- 코드: render 카메라 구간의 `cs.pv`(현재), `cs.pt`(목표), `cs.plock`(고정). 값이 0이면 예전 시점과 완전히 같아요.
- 터치(모바일)는 마우스가 없어서 해당 없음.

# 위치 정리
- 폭포: 월드 좌표 x≈-300, z≈690 (호국의 다리 x=0 에서 서쪽 300). 게임 화면은 +z 를 보기 때문에 -x 는 **화면 오른쪽**.
- 강: 폭포 → 동쪽(화면 왼쪽)으로 흘러 다리 밑 → x≈548 바위산 동굴.
- 비행기: 고정 자리 없이 플레이어 앞 600 거리를 날아요 (3분마다).

# 폭포 2개 + 언덕 오르기 + 물안개 (V60)
- **언덕 진입**: 서쪽 협곡 언덕과 동쪽 바위산 모두 올라갈 수 있어요. 지형 높이를 `groundHeightAt` 에 합치고(`RIVER.hh`), 이동 때 `landPush` 안에서 `RIVER.push` 가 너무 가파른 경사(≈60° 이상)만 막아요. 꼭대기에서 폭포 바로 위(y≈70)까지 걸어갈 수 있고, 강물(다리 길 제외)은 그대로 못 들어가요. 절벽 상자 막이/카메라 막이는 없앴어요 (카메라는 기존 "땅 위 9" 규칙이 처리).
- **폭포 2개**: 서쪽(절벽 면을 따라) + 동쪽 바위산(수직 벽, 이전 동굴 입구 대신). 동쪽은 위 물길(y≈HL)이 있고 같은 효과예요. `makeFall(cfg)`.
- **물줄기 효과**: 겹친 두 장(앞/뒤 위상 다름), 빠른 세로 줄무늬 + 뭉치(덩어리) 흐름, 물결치는 정점 흔들림, 아래쪽 하얀 물보라. 튀는 물방울 380개/폭포가 절벽 면을 따라 떨어지다 바깥으로 튀어요.
- **물안개**: 떨어지는 자리에서 위로 피어오르며 하류 쪽으로 번지는 스프라이트 + 수면 위에 낮게 깔리는 안개. 밤에는 어두워져요. 물 셰이더의 폭포 아래 거품에는 퍼지는 물결 고리도 추가.
- **물 입체감**: 겹친 파도(세 방향) + 법선 강화 + 확산광, 햇빛 반짝임(작은 알갱이), 물밑 빛무늬(코스틱, 얕은 곳), 얕은 곳은 더 투명, 강바닥을 더 깊게(-2.4) + 물밑 돌.
- **버그 수정**: 캐릭터 뒤에 회색 네모가 보이던 문제 → 물/폭포의 그리기 순서(renderOrder -5~-3)를 캐릭터보다 먼저로.
- 검수: 오류 없음, 이동 시뮬레이션(서쪽 언덕 N·W에서 등반, 꼭대기 가로지르기, 동쪽 바위산 N→S 종단, 강물 막힘, 다리 건너기) 통과. 실제 GPU 프레임은 미확인.

# 폭포 구간 원본 사진 재현 (V61)
원본: `source-images/waterfall_reference_original.webp` (로우폴리 협곡 폭포, 좁은 개울, 큰 소나무, 판자 다리).
- **지형**: 폭포 뒤 큰 절벽 + **개울 옆 풀밭 둔덕 + 양옆 절벽** (gorgeH 를 head 벽 / 옆 terrace / 옆 절벽으로 재구성). 개울은 좁게(폭 ≈30~40) 폭포에서 시작해 다리 쪽에서 120까지 넓어져요.
- **폭포**: 폭 좁은 물줄기 + **솜뭉치 같은 하얀 거품 덩어리 120개**(InstancedMesh)가 절벽 면을 따라 떨어지고, 아래에서 뭉게뭉게 솟는 거품 더미 50개. 물방울·안개 유지. 동쪽 폭포도 같은 방식(높이에 맞춰 크기 축소).
- **나무**: 사진처럼 붉은 갈색 줄기 + 아래로 처진 납작한 초록 잎 조각이 층층이(PETAL) 있는 소나무, 자작나무, 덤불, 꽃, 버섯, 통나무, 키 큰 풀, 물가 바위, 개울을 건너는 작은 나무 판자 다리(x=-175).
- **선명도**: 폭포 구간의 지형/나무/바위/물에 안개(fog)를 꺼서 멀리서도 흐려지지 않게 했어요 (물/폭포 셰이더 안개는 3배 먼 거리).
- **자유 이동**: 강물에도 들어갈 수 있고(수면 y=-0.25 위를 헤엄), 언덕은 약 70° 이상 절벽만 못 올라가요. 폭포 위 고원 꼭대기와 동쪽 바위산 종단 모두 가능.
- 검수: 오류 없음. 이동 시뮬레이션(서쪽 언덕 등반, 폭포 위 고원 끝, 개울 건너기, 큰 강 헤엄, 동쪽 바위산 종단, 다리 건너기) 통과. 낮/밤 화면 확인.
