> 갓루다님이 정한 **앞으로의 목표**예요. 새 작업을 시작할 때 이 문서를 먼저 읽고, 작업이 끝나면 아래 "진행 체크리스트"를 갱신해요.

게임 안에서 석판 길 앞에 서서 북쪽을 바라봤을 때, 아래 기준 사진과 **같은 위치, 같은 구도, 같은 빽빽함과 퀄리티**로 보이는 농촌 마을을 만든다.

## 2. 기준 사진 분석 (구현해야 할 것)

기준 사진에 보이는 구성이에요. 숫자는 눈대중이니 구현하면서 맞춰요.

| 영역 | 내용 |
|---|---|
| 앞쪽 | 가로로 지나가는 **석판 포장길**, 그 앞에 풀밭 띠. 캐릭터는 석판길 앞에 서 있음 |
| 정중앙 | **큰 기와집 대저택**(ㅁ자 한옥, 담과 대문 포함). 대문 앞으로 **흙길 한 줄**이 곧게 나 있고, 앞마당은 흙 |
| 흙길 양옆 | 왼쪽: 붉은 벽돌 2층 양옥, 파란 슬레이트 단층집, 위성안테나 달린 회색 콘크리트집, 터널 비닐하우스(투명), 자전거 줄. 오른쪽: 기와집, 초록 지붕집, 파란/붉은 양철지붕집, 슬레이트 창고, 터널 비닐하우스, 텃밭 고랑 |
| 집 사이 | 흙길이 가지처럼 갈라지고, 집마다 마당 소품(장독, 장작, 빨랫줄, 통, 자전거, 위성안테나) |
| 뒤쪽 | 낮은 돌담, 먼 마을 지붕들, 큰 나무 2그루(빌보드가 아닌 3D로), 전봇대 |
| 땅 | 흙과 풀이 부드럽게 섞임(경계가 딱 끊기지 않음) |
| 카메라 | 석판길 뒤에서 **높이 내려다보는 시점**(마을 전체가 한눈에) |

핵심 인상: **집이 20~30채 빽빽하게 모여 있는데도 집마다 지붕과 벽이 서로 잘 맞고, 소품이 많아 생활감이 있다.**

## 3. 위치 (⚠ 확정 필요)

- "똑같이 **그 위치**에 구현"이 목표인데, 사진 속 정확한 좌표를 아직 확정하지 못했어요.
- 확정 방법: 갓루다님이 그 자리에 섰을 때 **화면 위 HUD에 뜨는 장소 이름**(예: "칠곡 농촌 마을 · 2구역 장터 골목")을 알려주시면 좌표를 정할 수 있어요.
- 현재 구현 위치: 큰길(z=45) **북쪽** 블록, 좌표 x -715 ~ -1125, z -30 ~ 186 (1구역 골목과 6구역 정자마당 사이). 기준 사진 위치가 이곳이 아니면 이동/확장해야 해요.
- 석판길 앞이어야 하므로, 위치가 확정되면 **그 앞 길을 석판 포장길로 바꿀지**도 같이 결정해요.

## 4. 현재 상태와 목표 사이의 격차 (V35 기준)

| 항목 | 현재 | 목표까지 |
|---|---|---|
| 건물 수 | 큰 기와집 1 + 북쪽 3줄 집(대략 20채) | 기준 사진처럼 25~30채, 크기와 종류 다양 |
| 건물 선명도 | 집 시트 한 장에 10면을 넣어 **한 면 60~120px** → 흐림 | 건물마다 **한 면씩 1024px 이상**(아래 5번) |
| 집 모양 | 앞/옆/뒤 그림 + 속 덩어리 + 지붕 덩어리(기와/초가/양철/평지붕) | 지붕 윗면 이미지 + 옆면 양쪽이 있으면 훨씬 자연스러움 |
| 단면 집 | 초가/슬레이트/창고는 **같은 그림을 네 면에 붙임** | 건물별 옆면·뒷면 따로 |
| 땅 | 가장자리가 부드러운 흙/풀 마스크, 흙길 | 기준 사진의 흙길 가지, 집 마당 흙 패치, 석판길 |
| 소품 | 장독, 장작, 호박, 전봇대, 빨랫줄 등 3D 고정 | 위성안테나(지붕 위), 통, 자전거 줄, 텃밭 고랑 더 많이 |
| 카메라 | 마을 안(x < -670)에서 높이 +15, 뒤로 +14 | 기준 사진과 같은 높이/거리인지 비교 후 조정 |

## 5. 에셋 요청서 (제미나이에게)

**원칙: 한 장에 한 면.** 한 장에 여러 면을 넣으면 면당 픽셀이 줄어 흐려져요(실제로 집 시트가 그랬음).

1. 건물 하나씩, **흰 배경**, 건물이 이미지에 가득 차게(여백 최소), 가로 **1024px 이상**.
2. 정면 이미지를 먼저 올리고 "**같은 건물의 뒷면/옆면, 같은 시점·같은 조명·같은 높이**"로 요청 (정면/옆면/뒷면의 높이와 지붕선이 같아야 모서리가 맞음).
3. 좌우가 다른 건물은 **좌측면·우측면 둘 다**. 대칭이면 한쪽만.
4. 가능하면 **지붕 윗면(위에서 본 모습)** 한 장 — 카메라가 높아서 위에서 많이 보임.
5. **소품은 건물에서 따로**(자전거, 자판기, 우체통, 상자, 위성안테나, 통). 건물에 붙어 있으면 같이 잘려요.
6. 바닥 받침(돌판)은 그리지 않기. 간판 글자는 뒷면에 안 나오게.

우선순위: ① 큰 기와집(대문 포함) ② 가게(칠곡 종합상회) ③ 붉은 벽돌 양옥 ④ 파란 슬레이트집 ⑤ 초가 2종 ⑥ 기와 중형집 ⑦ 창고 2종 ⑧ 터널 비닐하우스(앞·옆).

## 6. 구현 규칙 (이미 배운 것, 어기면 문제가 생김)

- **카메라 파고듦**: 길가에 집이 붙으면 낮은 카메라가 지붕 속으로 들어가요. 마을 안 카메라를 높이고 멀리 둔 상태에서만 빽빽하게 지을 수 있고, **길 남쪽(카메라 쪽)에는 낮은 것(텃밭, 작은 소품)만** 둬요.
- **고정 3D**: 카메라를 따라 도는 그림 카드(빌보드)는 쓰지 않아요(항아리가 따라다녀 위화감). 사람(어르신)만 빌보드. 풀/나무는 그림 3장을 엇갈려 꽂은 고정 입체.
- **집 만들기**: 앞/옆/뒤 그림 전체(지붕 포함)를 네 면에 두르고 속은 집 종류에 맞는 덩어리(기와/초가/양철/평지붕)로 채움. 면 사이가 삐져나오지 않게 옆면 폭을 앞/뒷면 사이에 맞춤.
- **성능**: 움직이지 않는 물건은 같은 재질끼리 500유닛 칸으로 합쳐서 그림(배칭). 낫/탈것처럼 움직이거나 깜빡이는 것은 `userData.keep = true`로 제외. 마을 깊이 들어가면 먼 기존 맵 물건은 안 그림.
- **충돌**: 건물/담/큰 소품은 `VIL_RECTS`에 넣어요(걷기 테스트가 길을 막지 않는지 확인).
- **기존 맵 불변**: x ≥ -620(기존 맵)은 픽셀 하나도 바뀌면 안 됨. 반드시 `regress2.js` 12/12 동일 확인.
- 외부 키가 필요한 기능은 사용자가 직접 넣어야 함(CLAUDE.md의 외부 API 규칙).

## 7. 작업 순서 체크리스트

- [ ] 기준 사진 위치(HUD 장소 이름 또는 좌표) 확정
- [ ] 그 위치 앞 길을 석판 포장길로 정리, 마을이 길에 자연스럽게 이어지게
- [ ] 카메라 높이/거리를 기준 사진과 비교해 조정
- [ ] 고해상도 건물 시트(5번) 받아서 건물별로 교체 (큰 기와집 → 가게 → 양옥 순)
- [ ] 집 25~30채로 늘리고 종류/크기/방향 다양화, 길 가지(흙길) 추가
- [ ] 소품 추가: 지붕 위 위성안테나, 통, 자전거 줄, 텃밭 고랑, 터널 비닐하우스
- [ ] 걷기/성능/기존 맵 회귀 테스트(`zone_walk`, `cwalk`, `farm_test`, `regress2`) 통과 후 아티팩트 재게시
- [ ] 비닐하우스 구조물 매핑 시트(아직 못 받음) 반영
