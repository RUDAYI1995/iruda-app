## 현재 구조에서 구현하면 (방침 초안)
- 1P = 토끼(함곡이, `Rabbit` 행). 2P = 새 행 `Player2` (`units.csv`에 추가: 체력/공격력).
- 1P의 공격 행동(기본 공격, 뒷다리 차기)은 이미 `TM.batch` 묶음 안에서 `AttackCommand`로 실행됨 → 같은 묶음에 2P의 `AttackCommand`(지원)와 적의 반격 `AttackCommand`를 이어 붙이면 **우클릭 한 번에 전부 되돌려짐**.
- 순서(우선순위 번호): ① 1P 공격 → ② 지원 공격(우선순위 1) → ③ 반격(우선순위 2). 지원 공격으로 대상이 죽으면 반격은 발동하지 않음.
- 반격 연쇄 방지: 반격은 다시 반격을 부르지 않음(1회), 대상이 살아 있고 사거리 안일 때만.
- 연출: 1P 타격 → 0.25초 뒤 2P 지원 사격/타격 → 0.7초 뒤 적 반격(총알/타격 + 피해 숫자).

## 확정 + 구현 결과 (V77)
확정: 2P = **루샤(아군, 파란 옷으로 구분)**, 3D로 걷고 움직임, 나머지는 추천안.
- `units.csv`의 `Player2` 행(루샤 2P, 체력 250 / 공격력 35)으로 능력치 설정. 시작 타일은 토끼 옆(gx+2).
- 2P는 직접 공격하지 않음. 1P가 이동하면 3D로 걸어서 따라옴(토끼 오른쪽 2칸 근처).
- 지원 공격: 1P의 **기본 공격/뒷다리 차기** 때 2P가 같은 대상을 함께 공격(2P 기준 5칸 안, 대상이 아직 살아 있을 때).
- 반격: 맞은 북한군 병사·루샤(보스)·탱크가 살아 있고 5칸 안이면 자신을 공격한 상대(1P, 지원한 2P)에게 반격(명중 80%). 반격은 반격을 부르지 않음. 언덕 사수·전투기는 반격 없음, 일반 군인끼리의 사격에는 반격 없음.
- 순서: 1P 공격 → 지원 공격 → 반격. 지원으로 쓰러지면 반격 없음(검증: 체력 30/60/100 세 경우).
- 적 군인/탱크/전투기가 2P도 조준(체력바, 죽으면 쓰러짐). 패배 조건은 1P 사망 그대로.
- 우클릭 되돌리기: 이동(1P+2P), 공격+지원+반격이 한 묶음으로 되돌아감.
- 한계: 지원/반격 사거리(5)와 반격 명중률은 코드 상수(표에 없음). 2P는 직접 조작/스킬 없음. 2P 루샤는 보스 루샤 모델 재사용(파란 색조).
