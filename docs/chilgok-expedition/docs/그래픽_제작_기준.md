# 칠곡원정대 그래픽 제작 기준

기록일: 2026-10-27

## 확정된 사용자 요구

### 최신 품질 작업 지시

- 기존 농촌마을 리모델링 범위는 유지한다. 사용자는 목표 이미지 수준의 픽셀·화질·그래픽을 갖춘 자산 이미지를 먼저 만들고, 그에 맞춘 실제 입체 모델·재질로 맵에 적용하도록 다시 지시했다.
- 기존 이미지나 구체적인 배치를 보존하는 것보다 새 고품질 그래픽으로 교체하는 작업을 허용했다. 목표 이미지의 재질·선명도·입체감을 기준으로 검수한다.
- 이번 세부 작업은 한 장을 네 면으로 나눴던 벽 시트를 면별 원본 이미지로 교체하고, 기와·처마·꽃상자·석재·소품의 실제 형태를 개선한다. 전체 맵이 완성되었다고 보고하지 않는다.

### 최신 범위 정정: 기존 농촌마을에 통합

- 별도 게임이나 별도 '새 그래픽 개울마을'을 만들지 않는다. 기존 게임을 리모델링하는 작업이다.
- 제작한 자산은 기존 칠곡 농촌마을의 빈 공간에 어우러지도록 배치한다.
- 별도 개울마을 진입 화면과 버튼을 제거한다. 기존 링크 접근은 기존 게임으로 안내한다.
- 기존 농촌마을 7구역 구불 골목의 서쪽 끝 너머 빈 공간을 사용하고, 기존 논·비닐하우스·주택·골목·농사 체험을 보존한다.
- 기존 게임의 렌더러·카메라·캐릭터·입력·지도·저장·낮밤을 사용한다. 시범 페이지의 독립 루프와 캐릭터를 이식하지 않는다.
- 원본의 성·산을 기존 농촌마을에 배경 벽으로 덮지 않는다. 기존 칠곡 풍경과 연결되는 근경 자산부터 통합한다.

- PC와 휴대폰 모두에서 원활하게 동작하는 실제 3D 게임을 목표로 한다.
- 사용자가 승인한 콘셉트 이미지의 귀엽고 아름다운 동화풍 3D MMORPG 풍경을 시각 기준으로 삼는다.
- 기존 단순한 모노폴리풍 맵을 전면 개편하고 싶다는 요청이다. 평평한 바닥과 반복 도형을 개선한다.
- 그래픽 구현이 막히면 에이전트가 먼저 대상 풍경·소품·물건·3D 모델의 기준 이미지를 제작하고 이를 게임 구현의 기준으로 사용한다.
- 사용자의 요구 원문: “그 그림을 게임에 적용해서 반드시 원본과 똑같은 100% 일치한 화면과 풍경,소품,물건이 나오게 만들어야해”. 이는 사용자가 요청한 목표이며 기술적으로 달성되었거나 보장된 사실이 아니다.
- 이 기준은 매 작업 전에 다시 읽는다.

## 기준 이미지

- 파일: `reference/그래픽_목표_콘셉트.png`
- 생성 이미지이며 실제 게임 캡처가 아니다.
- 핵심: 자연스러운 지형 높낮이, 굽은 돌·흙길, 개울과 다리, 풍성한 나무와 꽃, 아늑한 마을, 먼 산의 깊이, 따뜻한 햇빛, 캐릭터와 배경의 일관된 입체감.
- 이미지의 개별 건물이나 성이 기존 칠곡 관광지를 대체하도록 승인된 것은 아니다. 실제 지역 구성과 랜드마크 반영 범위는 별도 확정한다.

## 제작과 검수 절차

### 2026-10-27 최신 제작 방식 결정

- 사용자 지시: Higgsfield를 사용하지 않는다. 18크레딧 3D 생성은 승인되지 않았으며 실행하지 않는다.
- 필요한 오브젝트마다 별도 이미지 시트를 만들고, 앞·옆·뒤·지붕 이미지를 실제 입체 구조의 각 면에 적용한다.
- 창틀·처마·기와·꽃상자 등 돌출부는 이미지의 음영만으로 입체라고 주장하지 않고 별도 형태로 구성·검수한다.
- 첫 대상은 원본 오른쪽 근경 집 한 채다. 기존 시범본의 단순한 건물을 품질 합격 자산으로 재사용하지 않는다.
- 모델 제작용 이미지 `reference/house-v2/house-model-input.png`는 원본을 참고한 생성 해석이다. 보이지 않는 면의 추정과 원본에서 확인된 면을 구분한다.

1. 기존 자산·공통 구현·이동·충돌·카메라·지도·상호작용과 패치 소스 관계부터 확인한다.
2. 그래픽 문제가 있으면 기준 이미지를 먼저 마련한다. 이미지는 설계 자료이며 자동으로 완전한 3D 모델이 되는 것은 아니다.
3. 기준을 바탕으로 입체 형태, 재질, 조명, 충돌과 필요한 애니메이션을 갖춘 게임용 자산을 제작·적용한다. 평면 그림을 붙여 완성된 입체 모델이라고 보고하지 않는다.
4. 동일한 카메라 위치·화각·화면비·시간대·조명 조건에서 기준과 게임 캡처를 비교한다. 형태·비율·색·재질·배치·그림자·깊이의 차이를 기록한다.
5. 여러 각도에서의 일관성과 실제 플레이를 검증한다. 단일 시점 비교만으로 모든 각도의 일치를 주장하지 않는다.
6. PC와 실제 휴대폰의 프레임 속도·메모리·로딩·조작을 확인한다. 실기기 검증을 하지 못하면 미검증으로 명시한다.

## 기술적 한계와 미확정 사항

- 단일 생성 이미지와 자유 이동 가능한 3D 환경의 모든 시점에서 100% 픽셀 일치는 보장할 수 없다. 일치율을 측정하지 않고 수치로 주장하지 않는다.
- 두 기기에서 같은 미술 방향을 유지하는 것과 모든 기기에서 동일한 렌더링·성능을 보장하는 것은 다르다. 품질 하향이나 자동 품질 조정은 사용자에게 알리지 않고 적용하지 않는다.
- 지원할 PC·휴대폰 및 브라우저, 최소 프레임 속도, 화면 비교의 허용 차이, 첫 시범 구역과 전체 지역 구성은 아직 미확정이다.
- 초기 `game/village/` 독립 시범 방식은 사용자의 최신 범위 정정으로 폐기했다. 현재 구현 위치는 기존 게임의 농촌마을 7구역 서쪽 빈 공간이며 `game/remodel/`의 조립 코드를 사용한다. 독립 시범 방식에 대한 과거 기록을 현재 승인으로 해석하지 않는다.
- PC·휴대폰의 최종 지원 범위와 성능 합격 수치 및 시각 허용 차이는 여전히 미확정이다. 시범 제작을 실기기 성능 보장이나 100% 일치 달성으로 보고하지 않는다.
