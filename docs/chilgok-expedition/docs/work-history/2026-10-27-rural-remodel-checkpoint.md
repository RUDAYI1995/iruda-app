## 작업 전 읽을 기준

AGENTS.md와 docs/그래픽_제작_기준.md를 먼저 읽는다. 이 작업은 기존 게임을 리모델링하는 작업이며 별도 개울마을 게임을 만들지 않는다. Higgsfield는 사용하지 않는다. 목표 이미지 수준의 고품질 자산 이미지를 먼저 제작하고 실제 입체 형태와 재질로 조립해 기존 맵에 적용한다.

## 현재 구현

- 기존 칠곡 농촌마을 7구역 구불 골목 서쪽 끝의 빈 공간에 주택·꽃밭·나무·돌길·수로·다리를 통합했다.
- 기존 골목 끝 (-1330,-450)과 새 구간을 연결했다. 새 영역은 x=-1845~-1395, z=-580~-320이다.
- 기존 캐릭터·입력·렌더러·지도·농사·저장·낮밤 체계를 사용한다.
- 벽면 정면은 1334×1179, 측면·후면은 각 1360×1157의 개별 원본 이미지를 사용한다. 돌길은 1672×941이다.
- 곡면 기와·석재 기초·목재 보·꽃상자·철제 등불 등 실제 돌출 구조를 보강했다. 작은 기와에 전체 기와 무늬를 반복하지 않도록 UV를 수정했다.
- 새 구간 안에서만 기존 카메라의 높이·바라보는 높이를 점진적으로 조정한다. 바깥 구역의 조정값은 0이다.
- 옛 game/village/index.html은 기존 게임으로 이동하는 안내만 제공한다. 독립 시범 코드와 이미지 원본은 이력으로 보존하되 해당 페이지에서 실행하지 않는다.

## 주요 파일

| 경로 | 역할 |
|---|---|
| game/index.html | 기존 게임과 지도·높이·통행·카메라·렌더 루프의 통합 훅 |
| game/remodel/rural-remodel.js | 빈 공간 보호 검사, 조경 배치, 기존 충돌과 높이 연결 |
| game/remodel/detailed-cottage.js | 면별 이미지를 적용한 입체 건축과 소품 조립 |
| game/remodel/assets/ | 생성한 이미지 시트와 고해상도 면별 자산 |
| docs/reference/ | 목표 콘셉트, 모델 입력 이미지와 실제 구현 화면 |
| tools/verify-rural-remodel.cjs | 기존 구역 보호와 통합 계약 검사 |
| preview-server.cjs | 선택 사항인 로컬 미리보기 서버 |

기존 src/ 패치 원본과 기존 문서·자산은 보존했다. 현재 실행 변경은 game/index.html과 remodel 모듈에 있다. 과거 패치 도구로 실행본을 다시 만들 때 이 통합 훅을 잃지 않도록 먼저 생성 관계를 확인해야 한다.

## 실행과 검증

프로젝트 폴더에서 node preview-server.cjs를 실행한 뒤 http://127.0.0.1:5182/index.html을 연다. 기존 지도에서 농촌마을 7구역 꽃길 정원으로 이동하거나 구불 골목 끝에서 걸어 들어간다.

- node tools/verify-rural-remodel.cjs: 통과.
- 리모델링 스크립트의 node --check: 통과.
- 기존 HTML 인라인 스크립트 14개 문법 파싱: 통과.
- 브라우저에서 이동·원래 7구역 보존·근접 모델 표시 확인. 검수 중 error 로그 없음.
- 부지 충돌 시 무설치, 기존 구역 높이·통행 보존, 연결로, 수로·다리, 카메라 등록과 경계 가중치, 이미지 실제 해상도·전체 UV·기와 UV 검사: 통과.
- 최초 기존 게임 실행에서 이미지가 준비되기 전 Texture marked for update but image is undefined 경고가 관측됐다. 원인을 확정하지 않았으며 error와 구분한다.

## 남은 작업과 불확실성

- 지형 높낮이, 물·물보라, 수목 형태·밀도, 전체 조명과 풍경 구성은 목표 이미지 수준에 아직 미달이다.
- 창문·꽃 등 일부 세부는 면 이미지의 표현이며 모든 잎·꽃잎이 개별 메시인 것은 아니다.
- 기존 캐릭터와 AI 루다 표현은 유지했으며 새 배경과 동일한 수준으로 교체한 상태는 아니다.
- 실제 휴대폰의 GPU·메모리·발열·장시간 실행 및 게임 전체 회귀는 미검증이다.
- 원본과 100% 동일하다고 보장하거나 완료로 기록하지 않는다.
