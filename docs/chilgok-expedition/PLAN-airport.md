# 스카이캣 공항 + 비행기 탑승 계획 (초안)
참고: `source-images/airport/terminal_reference.webp`(탑승장), `cabin_reference.webp`(기내)

## 구성
1. **탑승장** (하늘섬 맨 위 섬, SKY.top x1000 z2060 y395): 아치형 터미널(남색 지붕, 고양이 간판, 배너, 벤치), 하얀 돌 광장(원형 화단), 크리스털 가로등, 탑승교, 활주로에 정차한 스카이캣 비행기(3분 주기 비행기와 같은 모델).
2. **기내** (바닥 파란 카펫 통로, 파란 소파/좌석(고양이 귀), 금색 난간·계단, 둥근 창, 커튼, 라운지, 발자국 장식): 별도 방(하늘 위 따로 떨어진 좌표)으로 만들고 탑승하면 그곳으로 이동.
3. **비행**: 탑승하면 비행기가 맵을 돌아다녀요. F → 선장이 "어디에 내릴까요?" 목록(칠곡 명소/가산수피아/농촌마을/폭포/하늘섬 등).

## 정할 것 (갓루다님 선택 대기)
- F 키는 이미 "맵 확장"이라서 겹침 → 탑승 중에만 F 를 내리기로 쓰고 맵 확장은 버튼으로?
- 비행 방식: 자동 관광 경로 / 직접 조종
- 창밖: 하늘 + 구름 + 떠 있는 섬 그림 / 실제 맵이 아래로 지나가는 모습(무거움)
