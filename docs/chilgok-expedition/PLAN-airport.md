# 스카이캣 공항 + 기내 + 탑승 (V64)
참고: `source-images/airport/terminal_reference.webp`(탑승장), `cabin_reference.webp`(기내)

## 구현된 것
- **위치**: 마법 나무 꼭대기 큰 섬(crown, y600) **남쪽 끝(z≈2100)에서 돌다리**로 이어진 새 섬 `공항 섬`(중심 x1175 z2330, 반지름 170, y600). 기존 하늘섬 그림/지형은 건드리지 않았어요 (새 섬을 덧붙임).
- **탑승장**: 돌바닥 광장 + 원형 화단(바큇살 무늬), 아치 터미널(남색 지붕, 4 모서리 첨탑, "SKY CAT AIRLINES" 간판, 안쪽 벤치·전광판·화분), 고양이/발자국 남색 배너, 크리스털 가로등(돌며 떠요), 난간, 꽃나무, 화분, 활주로(노란 선), **주차된 스카이캣 비행기**(날아다니는 것과 같은 모델, 랜딩기어 포함), 유리 탑승교(GATE 1).
- **탑승**: 탑승교 끝에서 `E 눌러 스카이캣 항공 탑승하기` → 기내로 이동.
- **기내** (허공 x1960 z1500 y1000, 폭 70 × 길이 240): 파란 카펫(발자국), 고양이 귀 파란 좌석 16석(발자국 헤드레스트), 양쪽 둥근 창 12개(금테, 구름바다 + 떠 있는 섬 그림이 흘러가요), 커튼, 파란 라운지 소파 4 + 대리석 테이블·고양이 귀 램프·꽃병, 계단 난간 + 고양이 엠블럼, 천장 금빛 조명선 + 발자국 패널, 앞쪽 하늘섬 그림 액자 + 문, 뒤쪽 EXIT. 좌석·소파·테이블은 막혀 있고 벽은 못 나가며 카메라도 벽 밖으로 안 나가요(CAM_RECTS).
- **비행**: 탑승 6초 뒤 이륙, 이후 "지금 지나는 곳: 왜관 시내 → 호국의 다리·폭포 → … → 구름바다·하늘섬" 이 9초마다 바뀌어요.
- **내리기**: **J 키**(F는 맵 확장과 겹쳐서 J로 했어요) → 선장님 메뉴(왜관 시내, 호국의 다리, 폭포 개울가, 가산산성, 송림사, 칠곡보 생태공원, 칠곡호국평화기념관, 가산수피아, 칠곡 농촌 마을, 스카이캣 공항). 선택하면 그곳에 도착(첨벙 없이 플래시 + 안내 문구). 비행 전(주차 중)에는 뒤쪽 EXIT 에서 E 로도 내려요.
- 코드: `src/waterfall/block_X.js`, `block_P.js`(catPlaneClone 추가), 훅은 `patch_w.py`(skyBranchCands/villageHint/villageInteract0/J키/updateHud/tick).

## 한계 (참고 사진과 100% 같지는 않아요 — 필요한 것을 알려 주세요)
1. **질감/디테일**: 사진은 고급 렌더링(대리석·금속 반사, 부드러운 조명, 그림자)이라 도형+캔버스 텍스처로는 **분위기 근사**까지예요. 가장 효과가 큰 것: 사진 속 물체를 **배경 투명한 이미지(터미널 정면, 배너, 좌석, 소파, 창문 틀 등)** 로 주시면 입체 판/텍스처로 더 비슷하게 만들 수 있어요.
2. **하늘 배경**: 사진의 보라빛 구름하늘/떠 있는 성(멀리)은 기존 하늘섬 배경을 그대로 써서 똑같지 않아요. 공항 전용 하늘 그림을 주시면 연결할 수 있어요.
3. **비행기 크기/모양**: 주차 비행기는 날아다니는 모델의 0.64배라 사진(터미널보다 훨씬 큼)보다 작아요. 다리·창문 디테일은 단순해요. 크기 키우면 섬이 더 커져야 해요(조정 가능).
4. **기내**: 좌석 배치는 사진보다 단순(4열×4석), 천장 곡면/창 위 선반, 라운지 곡선 소파 등은 근사예요. 아래층으로 가는 계단은 난간만 있어요(내려갈 수 없음). 창밖 풍경은 그림 한 장이 흐르는 방식(실제 맵이 지나가진 않아요).
5. **비행**: 실제로 비행기가 움직이며 맵 위를 나는 건 아니고, 기내에서 창밖 그림 + 안내 문구로 표현해요(자동 관광). 직접 조종/실제 맵 투영은 미구현.
6. **성능/로딩**: 공항 섬은 첫 프레임에 한꺼번에 만들어서 순간적으로 살짝 끊길 수 있고, 근처에서만 그려요. 실제 PC 확인 필요.
7. 선장님 캐릭터/목소리는 없어요(메뉴 글만). 함곡이 3D 외 다른 캐릭터(그림 조각)도 탑승 가능.
8. 밤에는 기내가 낮보다 어두워요 (기내 조명 기본값으로 고정하는 것은 다음 단계).
