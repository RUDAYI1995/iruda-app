# 칠곡 턴제 전투 (V70) — 국군 100 : 북한군 100 + 루샤

## 흐름
1. 호국탑 가는 길(월드 z≈1930~2075)의 **국군 소대**에 다가가면 "전투를 시작할까요?" (Enter 시작 / Esc 나중에). 국군 소대가 길을 막고 있어서 이기기 전엔 지나갈 수 없어요.
2. 전투 시작: 카메라가 높아지고(조작 고정), 토끼가 국군 앞으로 가며 **북한군 100명이 줄지어 행군**해 와서 만나요 → **루샤 등장** "네 이 놈! 네놈이 내 유흥을 방해하는구나!" / "저놈들을 없애라!" → 턴제 시작.
3. 한 턴 = **우리 차례**(토끼가 이동 최대 3칸(방향키/WASD 한 번에 한 칸) + 행동 1회 → 끝나면 **국군 전체 자동 행동**) → **적 차례**(루샤 스킬 → 북한군 전체 자동 행동).
4. 행동 메뉴: 공격(1) · 방어(2) · 아이템(3) · 스킬(4: Q/W/E) · 후퇴(5) · 턴 종료(Space). 버튼으로도 가능.
5. 승리(루샤 HP 0): 루샤 대사 → 호국탑 "기념관 수호 완료" 처리(기존 스탬프 조건 `memorialCleared()` 충족) → 길이 열려요. 패배(토끼 HP 0 또는 국군 전멸): 처음부터 다시.

## 수치 (모두 `block_B.js` 상단/함수에서 조정)
- 국군/북한군 각 100명, HP 100, 총 한 발 40(루샤 저주 중 국군은 36). 사거리 5칸, 한 칸 전진(적과 2칸이 될 때까지) 후 사격, 사격 대상은 사거리 안 HP가 가장 낮은 적.
- 토끼 HP 300(갓루다님 미지정 → 임시값). 한 적 차례에 토끼가 맞는 총알은 최대 2발. 방어 = 피해 절반, 주먹밥 3개(+50), 공격 30(1칸 거리).
- 토끼 스킬: **Q 당근 나눠주기** 6칸 안 국군 HP +30(재사용 3턴) · **W 뒷다리 걷어차기** 1칸 앞 적 1명 −80(2턴) · **E 토끼의 유혹** 10칸 안 북한군 2명이 **2턴 동안** 토끼를 따라옴(공격 안 함)(4턴). ("10초"는 턴제라 2턴으로 바꿨어요)
- 루샤(HP 300): **Q 음침한 기운** 3턴간 국군 공격 40→36, 사용 후 6턴 재사용 불가 · **W 어둠의 손길** 국군 1명 **2턴** 세뇌(그 군인이 북한군 편이 됐다가 돌아옴)(3턴) · **E 사악한 미소** 딱 1번, 10턴 이후, 국군 전체 −10. 평소엔 사거리 5칸 공격.

## 구현 메모
- 격자: 칸 크기 5, 국군 10×10(z 1940~1985), 북한군 10×10(z 2030~2075), 루샤 뒤쪽. 화면 오른쪽 = gx 증가.
- 실시간 전투(기존 `updateBattle`/유닛 생성)는 끄고, `update()` 맨 앞에서 `tbActive()` 면 `tbFrame()` 으로 이동을 한 칸 이동으로 바꿔요.
- 루샤 이미지는 사진 배경이 있어 **다각형으로 오려냄**(`polycut.js`, 가장자리/보라 기운 일부 거침).

## 한계 / 필요한 것
- 병사 그림이 한 장(걷기·사격 동작 없음, 총 쏘는 선과 통통 튐으로 표현). 사격/피격/쓰러짐 이미지를 주시면 더 좋아져요. 100명이 한 화면에 있어서 가까이 보면 서로 겹쳐 보여요.
- 루샤는 **배경 투명 PNG**(보라 기운 포함)를 주시면 깔끔해져요.
- 국군 100 vs 10명: 처음엔 10명이라 하셨다가 100명으로 정하셔서 100으로 만들었어요(`NSIDE`/`setupFormation`에서 줄일 수 있어요).
- 전투가 길어요(전체 수십 턴 가능). 각 턴을 더 빠르게/군인 행동을 묶을지 플레이해 보고 알려 주세요.
- 실제 PC 성능(스프라이트 200개 + 선/글자)은 확인 못 했어요.

## V72 — 우클릭 되돌리기 · 토끼 시점 · 총알/포탄 · 체력바 · 탱크
- **명령 패턴** (`src/battle/block_B.js`): `ICommand{execute,undo}` → `AttackCommand`(명중 시 피해 적용/undo로 복구), `MoveCommand`, `SnapCommand`(방어·아이템·스킬·라운드 정리). `TurnManager`(코드명 `TM`)의 `commandHistory` 스택에 push.
- **우클릭(또는 Z)**: pop → undo. 적 행동 직후엔 국군/플레이어 행동이 나올 때까지 연속 undo(적 차례 전체), 그다음 우클릭은 국군 일제사격 묶음, 그다음은 내 행동 하나씩. 적 행동은 `AttackCommand`로 실행(1초 대기 코드 대체).
- **시점**: 칠곡원정대 기본 따라가기 시점(토끼 뒤, 약간 높게)으로 변경. 이동은 기존 한 칸씩.
- **총격**: 총알이 총구에서 날아가 명중(-40, 불꽃) 또는 빗나감(MISS, 먼지). 연사 느낌의 추가 탄 포함. 명중률 국군→적 75%, 적→토끼 55%, 루샤 90%.
- **탱크**: 국군 탱크는 국군 뒤, 북한군 탱크는 북한군 뒤. 차 차례마다 포탑이 돌아 포탄(포물선) 발사 → 폭발·연기, 대상 -60, 주변 1칸 -25. HP 300, 파괴되면 잔해로 연기.
- **체력바**: 모든 유닛(군인/토끼/루샤/탱크) 머리 위 작은 바.
- 한계: 탱크는 이동 없음(고정 포대), 명중률/피해량은 임의 값(조정 가능), 국군 공격 단추는 토끼의 근접 공격이고 국군 사격은 턴 종료 때 일제 발사, 실제 GPU 프레임 속도는 미측정.

## V73 — 시트 얼굴 군인 · 뒷다리 차기 · 하트 유혹 · 대형 탱크
- **군인**: 갓루다님이 준 국군/북한군 시트의 얼굴을 3D 머리에 입히고, 로우폴리(면이 보이는) 군복·갈색 군화·가슴 주머니/멜빵·북한군 챙모자+붉은 별로 시트 느낌에 맞춤. 크기 1.1배(격자 5칸 간격이라 더 키우면 겹침). 걷기/조준/사격은 3D 관절이라 자연스럽게 움직여요(2D 시트 그림은 걷는 프레임이 없어 불가).
- **뒷다리 걷어차기(W)**: 함곡이 3D가 적을 등지고 앞으로 숙여 두 뒷다리를 뒤로 차는 모션 → 타격 지점에 충격파/폭발/💥 KICK!/화면 흔들림.
- **토끼의 유혹(E)**: 두 팔을 들고 뛰며 빨간 하트 46개가 사방으로 퍼지고, 유혹된 북한군 머리 위에도 하트.
- **탱크**: 3배 확대, HP 190, 포탄 85 데미지(맞은 곳 + 가장 가까운 2명, 총 3명). 자기 편 군인이 모두 쓰러진 뒤에야 나서요(국군은 군인 전멸 + 탱크 파괴 시 패배). 국군 탱크 gz -19(국군 뒤), 북한군 탱크 gz 31(북한군 뒤). 포탄 폭발: 섬광·불꽃·충격 링·파편·연기 기둥·화면 흔들림.
- 한계: 군인 3배 확대는 격자 간격(5) 때문에 겹쳐서 1.1배로 제한. 얼굴은 시트 정면 이미지를 머리 앞에 붙인 것이라 옆/뒤는 단색. 탱크는 이동 없는 고정 포대. 실제 PC 프레임 속도 미측정.

## V74 — 유닛 데이터 시트 (체력/공격력)
- `data/units.csv` (구글 시트·엑셀에서 열어 편집): 열 `id,name,hp,atk`. 행: **Player**(국군 병사), **Enemy**(북한군 병사) + 선택 행 Rabbit / Lucia / TankPlayer / TankEnemy.
- 코드: `UnitData{id,name,hp,atk}` 객체를 시트에서 만들어 전투 편성(`setupFormation`) 때 체력으로 설정, 공격(`AttackCommand`)은 공격 주체의 `atk`만큼 대상 `hp`를 깎아요. 체력바/회복 상한도 시트의 hp 기준.
- 적용 방법: 이 CSV를 고치고 빌드하면 내장되고, 구글 시트 '웹에 게시 → CSV' 주소를 `UNIT_SHEET_URL`(또는 브라우저 localStorage `unitSheetUrl`)에 넣으면 시작 때 읽어와요(실패 시 내장 표). 개발 중엔 콘솔에서 `UnitSheet.load("id,name,hp,atk\n...")`.
- 기본값 = 기존 값(국군/북한군 100·40, 토끼 300·30, 루샤 300·40, 탱크 190·85). 국군은 루샤 '음침한 기운' 중 공격력 ×0.9.
- 한계: 스킬 고정 값(뒷다리 차기 80, 루샤 사악한 미소 -10, 당근 +30, 주먹밥 +50)은 아직 시트에 없음. 구글 시트 직접 읽기는 게시 환경의 외부 요청 허용 여부에 따라 막힐 수 있음(미검증).

## V75 — 자유 이동 사격 · 전투기 · 탱크 2대 · 언덕 그림자 수정
- **자유 이동**: 대열 유지 대신 각 군인이 매 턴 2~3칸 흩어져 이동(적과 3~4칸 유지, 동료와 겹치지 않게 퍼짐, 산/언덕 셀은 진입 불가)하고 1번 사격. 가로 폭 ±22칸. 처음 편성만 대열.
- **전투기**: 국군/북한군 각 1대(체력 350, 시트 PlanePlayer/PlaneEnemy). 전장 위를 선회하다 자기 차례에 3명을 기총 소사. 군인 사격으로 같은 데미지를 입고(비행기엔 명중 35%·확률 10%만 조준), 0이 되면 연기를 뿜으며 추락 → 땅에서 폭발 후 불타는 잔해. **폭발 주변 피해 없음.**
- **탱크 2대씩**(좌우 gx ±5). 자기 편 군인이 모두 쓰러진 뒤에 나섬(변경 없음), 탱크 둘 다 파괴돼야 국군 패배.
- **언덕 오류 수정**: 언덕 메시가 자기 그림자를 만들어 비탈에서 하얀/검은 네모가 번쩍임 → 언덕 그림자 생성 끔 + 그림자 bias/normalBias 조정 + 그림자 창을 텍셀 단위로 이동. 캐릭터 그림자판은 비탈 경사에 맞춰 눕고 파묻히지 않게 보정.
- 한계: 비행기는 직선 소사 + 선회(공중전/회피 기동 없음). 언덕 번쩍임은 제 환경(소프트웨어 렌더)에서 사용자 화면과 똑같은 현상을 재현하진 못하고, 원인 후보(그림자)를 고친 것이므로 PC에서 재확인 필요.

## 걷기 품질 원인 분석 (냉정)
- 루샤/함곡이/3D 군인이 자연스러운 건 **원본 그림이 아니라 내가 코드로 새로 만든 3D 모델(구·원통 조각에 관절)** 이라서 팔다리가 구부러짐.
- 시트 그림(국군/북한군/토끼 원본)은 **한 장짜리 2D 그림**(서 있는 1장, 뒷모습 달리기 2장)이라 다리를 구부릴 수 없음 → 통째로 흔들기/프레임 교체만 가능해 표지판처럼 보임.
- 나머지 6 캐릭터는 3D 시트가 없어 아직 2D 스프라이트 → 자연스럽게 못 걸음.
- 해결안: (A) 시트 속 인물을 **GLB 3D 모델(뼈대 포함)** 로 만들어 받기(Meshy/Tripo/Rodin 등 + Mixamo 걷기), 또는 (B) **부위별 분리 PNG 레이어**(머리/몸통/위팔/아래팔/허벅지/정강이/발/소총)를 받아 종이인형 방식으로 관절 애니메이션. 제가 직접 그림→3D 변환은 불가.

## V76 — 언덕 기관총/저격수
- 전투 구역(z 1700~2550) 언덕마다 **기관총 1명 + 저격수 2명**을 중턱(y 26~55, 전장 쪽 비탈)에 배치. 화면 왼쪽(+x) 언덕 3개 = 북한군(기관총 3 + 저격수 6), 오른쪽(-x) 언덕 4개 = 국군(기관총 4 + 저격수 8). 모래주머니/삼각대 기관총/위장 덤불+긴 총 진지 포함.
- 기관총: 차례마다 4연발(25, 명중 50%) / 저격수: 1발(70, 명중 85%, 가끔 적 언덕 사수·루샤·토끼 조준). 시트 행 MgPlayer/MgEnemy/SniperPlayer/SniperEnemy(체력 150/60).
- 언덕 사수도 체력바·피격·쓰러짐·되돌리기(우클릭) 적용. 전투기 지원과 별개.
- 한계: 맵에 전투 구역 언덕이 왼쪽 3개/오른쪽 4개뿐이라 "한 언덕에 1명" 규칙에서 북한군 기관총은 3명(요청 4명). 4개로 맞추려면 왼쪽에 언덕을 하나 더 만들어야 함. 진지 위치/높이는 자동 계산.

## V78 — 자연 전투(난전) + 1000 : 1000 + 다시 시작
- **흐름**: 호국탑 가는 길에 다가가면 먼저 **자연 전투**가 벌어지고(국군 1000 : 북한군 1000이 실시간 무작위로 서로 싸움: 가까운 적을 찾아 다가가 사격, 명중률은 거리별, 3발이면 쓰러짐, 탱크 포격 + 폭발 피해), 안내 메시지는 **"턴제게임 전투를 시작할까요?"**. 시작하면 화면이 어두워졌다가 처음 대열(40열×25행)로 턴제 전투가 시작돼요.
- **다시 시작**: 승리/패배/후퇴 후 자연 전투 상태로 돌아가고 8초 뒤 가까이 가면 다시 물어봐요(승리 보상·저장은 처음 한 번만 지급, 이후 승리는 토스트만).
- **1000 : 1000 턴제**: 격자 40×25 대열, 탱크 2대씩 (gx ±10, 군인 뒤), 루샤는 군인 뒤. 한 차례 계산은 거리장(BFS)과 점유 지도 탐색으로 빨라짐(이 환경 측정: 국군 일제사격 계산 41ms).
- **성능 대책**: 화면 밖 군인은 갱신 생략, 멀수록 2~3프레임에 한 번 갱신, 죽은 군인은 한 번만 숨김, 체력바는 다친/가까운 군인만, 모델 폴리곤 축소. 측정(이 환경 CPU): 자연 전투 시뮬 ≈ 2~6ms + 군인 애니메이션 ≈ 6~9ms.
- 한계: GPU 프레임 속도는 이 환경에서 측정 불가(소프트웨어 렌더). 저사양 PC에서 느리면 알려주세요(군인 수/모델 단계 조절 가능). 자연 전투는 전투기 소사·언덕 사수 없이 군인+탱크만. 턴제 시작 시 부대가 처음 위치로 리셋돼요.

## V79 — 목표 점령 · 30초 자유 이동 · 구역 긴급 무전 · 다양한 전투 동작
- **아군 루샤 제거**: 내 팀 루샤(2P)는 없앰. **적 보스 루샤 = 2P**, 데이터 표 `Player2` 행(체력 300 / 공격력 40)으로 설정. (지원 공격은 아군 2P가 없어져 사라지고 **반격**만 유지)
- **넓어진 전장**: 가로 ±170(언덕 사면 제외), 세로 z 1780~2340. 군인은 돌진하며 언덕 옆으로 퍼져 나갈 수 있음(산 위로는 못 올라감).
- **목표**: 국군 = 북한군 뒤 **호국탑(z≈2315)** 점령, 북한군 = 왜관시내로 가는 **남쪽 진입로(z≈1800)** 점령(왜관시내 본체는 z≈0이라 전장에 담을 수 없어 진입로를 점령 지점으로 사용). 매 라운드 끝에 점령 지점 반경 48 안의 공격 병력 − 방어×1.5(최대 +40)만큼 점령도 상승, 공격 병력이 없으면 −10, 100%면 점령(국군 점령=승리, 북한군 점령=패배). 루샤를 쓰러뜨려도 승리(기존). 점령도는 우클릭 되돌리기에 포함.
- **30초 턴**: 우리 차례마다 최대 30초(HUD ⏱). 1P는 마음대로 돌아다님(Space로 일찍 끝내기, 0초면 자동 종료). 행동(공격/스킬/방어/아이템) 직전 이동이 기록되어 우클릭 시 위치도 되돌아감. 북한군은 AI라 바로 진행.
- **전투구역 1~4**(가로 띠, 남쪽=1 진입로 … 북쪽=4 호국탑): 왼쪽 패널에 구역별 국군:북한군. 국군이 밀리는 구역(국군 ≥1, 북한군 ≥20 이고 1.4배 이상)이 생기면 **국군 얼굴 + "긴급! N구역이 위험하다! 여기로 와달라!"** 팝업 + 무전 효과음(찌직·삐삐 + 한국어 음성합성) + 해당 구역 바닥 붉은 표시.
- **전투 동작 추가**: 전력 질주(멀면 돌진, 총검 장착), **총검 찌르기(데미지 60, 시트 `Bayonet` 행)**, 맞으면 어깨를 움켜쥐고 아파함, 무릎쏴, 장전, 뒤쪽 병사에게 손짓, 앞을 가리키기(무작위 제스처). 가까운 적이 바로 앞이면 찌르기 우선(70%).
- 한계: 무전 음성은 브라우저 음성합성 + 효과음이라 기기마다 음색이 다르고 이 환경에서는 소리를 직접 확인하지 못함. 왜관시내 본체는 전장에 없음(진입로로 대체). 구역/점령 수치는 코드 상수. 군인 동작은 절차 생성 3D라 사람 모션 캡처 수준은 아님.
